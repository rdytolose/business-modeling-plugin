# BPMN

Прочитать BOOK_NOTES.md: BPMN и оговорки, книгу с. 44–73, приложения с. 125–130.
При расхождении сверить OMG BPMN 2.0.2 по ссылке индекса. Определить участников
и границы процессов: sequence flow внутри пула, message flow между участниками;
дорожки показывают ответственность. Ассоциация данных не является управлением.
Типы задач/событий выбрать по реальному смыслу. Проверить условия XOR/OR,
ожидание AND, исключения, циклы, подпроцессы и достижимость завершения.
Не синхронизировать взаимоисключающие пути без основания. Отмену/компенсацию
не подменять обычной доработкой. Учебные ограничения по числу стрелок не
объявлять всеобщими правилами BPMN. Установить редактор и формат: при выборе
BPMN XML обеспечить IDs, корректные ссылки, BPMN DI и реальную проверку импорта.
Картинка не подтверждает исполнимость модели в BPMS. JSON IDEF0 не использовать.
