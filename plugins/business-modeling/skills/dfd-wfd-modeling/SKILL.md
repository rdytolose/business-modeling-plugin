# DFD/WFD и карты процессов

Прочитать BOOK_NOTES.md: другие подходы, книгу с. 107–117 и приложения с. 138–139.
Для DFD установить вариант нотации и редактор; различать процесс, поток данных,
хранилище и внешнюю сущность. Проверить достаточность входных данных для
выходов, осмысленные преобразования, словарь данных и баланс внешних
интерфейсов при детализации. Для WFD проверить порядок, условия, ожидания,
завершение и исключения; поток управления не является потоком данных.
Карта процессов показывает состав и основные связи процессов, не подробный
сценарий исполнения. Диаграммы разных нотаций согласовывать по смыслу и
границам; число фигур может различаться. Не переносить в DFD правила
ICOM/3–6 из профиля IDEF0. Установить формат импорта, не использовать его JSON.
