# UML

Прочитать UML_RULES.md, LECTURES_INDEX.md и нужные PDF-страницы лекций из индекса.
При споре открыть локальный OMG UML 2.5.1. Установить стадию анализа,
проектирования или реализации; не добавлять поля БД и методы без основания.
Для use case проверить внешних актеров, цели, направления include/extend и
обобщения. Для классов — смысл ассоциаций, кратности, зависимости и жизненный
цикл при композиции. Для деятельности — guards, decision/merge и fork/join,
достижимость завершения. Для взаимодействий — порядок сообщений, участников,
условия и согласование с операциями классов. Состояния относятся к объекту;
компонент, артефакт и узел развертывания не взаимозаменяемы.
Согласовать сущности и сценарии между диаграммами. Для импорта выбрать формат
указанного редактора; PlantUML допустим только как явно согласованный исходник,
а не универсальный импорт UML. JSON IDEF0 здесь не использовать.
